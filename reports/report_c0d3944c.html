📊 Approach & Query

Query Code


SELECT 
  region,
  ROUND(SUM(total_amount), 2) as total_revenue,
  COUNT(*) as total_transactions,
  COUNT(DISTINCT category) as distinct_categories,
  ROUND(AVG(total_amount), 2) as avg_transaction_value
FROM read_parquet('data/gold_layer/*.parquet', union_by_name=true)
WHERE region IS NOT NULL 
  AND category IS NOT NULL 
  AND total_amount IS NOT NULL
GROUP BY region
ORDER BY total_revenue DESC

Query Description

Used SQL window functions with ROW_NUMBER() to rank categories by total_amount within each region. First aggregated sales by region and category using SUM(total_amount), then applied PARTITION BY region ORDER BY total_revenue DESC to identify the top performer in each region. Supplementary queries provided transaction counts, category distributions, and comparative analysis across all regions and categories.
